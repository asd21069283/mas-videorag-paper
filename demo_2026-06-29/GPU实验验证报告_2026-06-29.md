# 论文进展 · GPU 实机验证报告

> 刘子轴 ｜ 2026-06-29 ｜ 项目：MAS + 多模态 RAG 视频系统（视频+文字 → 图+文字）

## 1. 目的
验证老师拍板的核心路线——**"输出图 = 基于关键帧生成新图"（Q4）**——在**真实 GPU** 上跑不跑得通，以及评测指标可不可用。即把方案从"纸面"推进到"有实机证据"。

## 2. 环境（真机，非模拟）
- 平台：AutoDL **RTX 4090D 24GB**
- 框架：PyTorch **2.5.1 + CUDA 12.4**，diffusers 0.38.0
- 生成模型：SDXL-Turbo（快速概念验证用）

## 3. 实验（端到端三步）
1. **生成一张"关键帧"图**（模拟从视频里抽到的帧）：*红色跑车停在剧院门口*。
2. **以该关键帧为条件 + 文字指令**（*同一辆红车，行驶在雪景、黄昏*）→ **生成一张新图**。
3. **自动评测**：CLIP 主体一致性（关键帧↔生成图）+ CLIP 图文对齐（生成图↔指令）。

| 指标 | 数值 | 含义 |

| **主体一致性**（关键帧 ↔ 生成图） | **0.818** | 高——"那辆红车"在新图里被保住，证明生成是**被关键帧条件约束**的，不是瞎画 |

## 5. 结论
- ✅ **"关键帧条件生成新图"这条核心路线，在 4090 上真跑通了**（对应 GitHub issue #3 生成路线）。
- ✅ **评测脚本可用**（主体一致 / 图文对齐，对应 issue #6 评测）。
- 这是从"方案设计"到"有实机数据"的第一步。
