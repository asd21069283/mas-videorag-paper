Conventions. The joint accuracies use $n=1000$ as denominator; a sample whose grounding returns no box has no IoU and is counted as incorrect, so it cannot inflate accuracy. The diagnostic spatial IoU when temporally correct is averaged only over temporal hits that produced a box; grounding returns a box on 96.6\% of temporal hits, so 18/524 are excluded, and scoring them as IoU 0 would give 0.641 instead of 0.664. The headline accuracies are unaffected by this choice. The strict temporal convention (pad 0) is shared with a secondary evaluation tool whose default pad is 0.5\,s; that tool uses a fixed-reference spatial-gold convention rather than the nearest-in-time tube box used here, so the two agree on temporal gating but are not expected to match box for box, and the headline joint accuracies are defined by the nearest-in-time convention. The evaluated $n$ counts video-ready samples from the community mirror; the full 1901-clip test split is fetched, and a full-split run is straightforward. All reported figures in Sections~\ref{sec:exp-e2e} to \ref{sec:exp-faith} were independently recomputed from the raw per-sample records in multiple verification passes; the discrepancies surfaced (one development-set comparison quoted from a mismatched run and several rounding-level errata) were corrected, after which every figure matches the raw data.

\section{Bottleneck Decomposition}\label{app:decomp}

This appendix supports Section~\ref{sec:exp-oracle}: the selection-strategy baselines, the exact factorization of joint accuracy, and the gold-window tercile analysis. For any selector, joint accuracy at threshold $\tau$ factorizes as $A(\tau) = R_t \cdot S_t(\tau)$, where $R_t$ is temporal recall (keyframe inside the gold window) and $S_t$ is conditional spatial precision (IoU $\ge \tau$ given a temporally correct keyframe); the identity follows from the joint metric's definition and holds exactly on all nine selector runs at both thresholds. $S_t$ stays in a 0.78--0.81 band for every content selector while $R_t$ spans 0.35--1.00, so the entire selectable gap lives in timing; the temporal-oracle ceiling $A_{\mathrm{oracle}} = 1 \cdot S_t = 0.787$ is mechanically the conditional spatial precision.
